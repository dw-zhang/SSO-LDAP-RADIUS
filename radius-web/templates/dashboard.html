快速上手

  1. 加账号：「账号管理」→ 填用户名/密码，可勾选动态 VLAN（认证通过后交换机把端口划入该 VLAN）。
  2. 加交换机/AC：「密钥管理」→ 一台设备一条记录、一把独立密钥，密钥留空自动生成随机值，同步填到设备侧 shared-key。
  3. 验证：「认证测试」→ 输入账号密码直接测，即时看到 Accept/Reject 和回包属性。
  4. 对接设备：「对接指南」→ 华为 802.1X / 动态 VLAN / MAC 认证配置模板，直接照抄。

注意：网页上做的修改实时写入配置文件，但需要执行 cd /opt/SharkSSO/radius && docker compose restart 后才对认证生效（页面操作后会有黄色提醒）。
