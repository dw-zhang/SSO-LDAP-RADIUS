阶段 0：连通性（不通后面全白搭）

用户视图执行，-a 指定源 IP 模拟真实认证报文
ping -a {{ ac_ip }} 10.10.0.41

不通 → 到核心 172.16.1.254 上补路由：去 10.10.0.0/16 的路由已存在则查回程（10.10.0.41 网关必须能回 172.16.1.0/24）。

阶段 1：RADIUS 对接（新增，不影响现有用户）

system-view 后整段粘贴
radius-server template sharksso
 radius-server authentication 10.10.0.41 1812
 radius-server accounting 10.10.0.41 1813
 radius-server shared-key cipher {{ ac_secret }}
 radius-server retransmit 3
 radius-server source interface Vlanif10
quit
aaa

  authentication-mode radius
 quit
 accounting-scheme sharksso_acc
  accounting-mode radius
  accounting start-fail online
 quit
 domain sharksso
  authentication-scheme sharksso
  accounting-scheme sharksso_acc
  radius-server sharksso

quit
dot1x-access-profile name dot1x_access_profile

quit
authentication-profile name dot1x_authen_profile
 dot1x-access-profile dot1x_access_profile
 access-domain sharksso
quit
security-profile name MY_1x

quit

EAP 中继模式：AC 不碰密码，校验全在 RADIUS（与 LDAP 方案匹配）。shared-key 已自动填入本机密钥。

阶段 2：试验 SSID（MY-Dot1x-Test）

业务 VLAN 99 只做兜底，认证成功后被 RADIUS 下发值覆盖
ssid-profile name MY_Dot1x_Test
 ssid MY-Dot1x-Test
quit
vap-profile name MY_Dot1x_Test

 ssid-profile MY_Dot1x_Test
 security-profile MY_1x
 authentication-profile dot1x_authen_profile

quit
ap-group name default

  vap-profile MY_Dot1x_Test wlan 6

  vap-profile MY_Dot1x_Test wlan 6

  vap-profile MY_Dot1x_Test wlan 6

quit
quit

wlan 6 是 default 组里未占用的编号；dynamic-vlan enable 若报命令不存在说明该版本不支持无线动态 VLAN，用户会留在 99。

阶段 3：验证（三层逐段来）

  1. 服务器侧：「认证测试」页输入 sim8021x / SimUser@Example1 → Accept（跳过 AC 单测 RADIUS）。
  2. AC 侧：用户视图执行下面命令 → 回复 Radius Authentication reply : OK。
  3. 真终端：手机连 MY-Dot1x-Test 输同账号 → 拿到 20 段 IP = 动态 VLAN 生效；没配 VLAN 的账号会落 99 段 = 兜底生效。
AC 上测 RADIUS 全链路
test-aaa sim8021x SimUser@Example1 radius-template sharksso
看在线用户的 VLAN / IP（真终端连上后执行）
display access-user username sim8021x verbose

先切 MY_Office（20），稳定一天再切 MY_Work（30）。模板原地改，AP 自动跟随，无需碰 ap-group：

切 MY_Office 为 802.1X

quit

切换后：员工连 MY_Office 会弹账号密码框（LDAP 账号 / 密码），所属部门对应 VLAN 自动下发；机器人、考勤机等 4 个 SSID 继续走 PSK 不受影响。前提：「动态 VLAN」页已把部门映射到已有 VLAN 号并保存。

真机排障对照表

现象原因 / 处理
ping -a 不通172.16.1.254 或 10.10.0.41 网关缺回程路由
test-aaa 超时源 IP 不对（确认 radius-server source interface Vlanif10）；密钥不一致；核对「密钥管理」页 IP 必须是 172.16.1.253
test-aaa Rejectusers 文件改后没 restart；账号密码错；「认证测试」页先单测排除 AC 因素
认证通过但 IP 在 99 段RADIUS 没下发 VLAN：账号没配 VLAN 或部门没在「动态 VLAN」页映射 —— 属正常兜底，不是故障
认证通过但拿不到 IPAP 接入交换机 trunk 没放行下发的 VLAN（AC 上联 GE0/0/1 已放行 2-4094，不用动）
dynamic-vlan enable 不存在版本不支持无线动态 VLAN，RADIUS 下发值会被忽略，用户固定在业务 VLAN

附：有线侧（交换机 802.1X / MAC 认证）要点

  • 接入端口动态 VLAN 必须 port link-type hybrid + dot1x enable；
  • 打印机 / IoT 走 MAC 认证：mac-authentication enable，账号 = MAC 地址（00-11-22-33-44-55 格式）在「账号管理」建同名账号；
  • 交换机侧验证：display dot1x interface g0/0/1（Authorized）、display access-user username xxx verbose（下发 VLAN）。
